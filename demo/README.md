# Демо-видео Tusche

Ролик для README: 1920×1080, 30 fps, ~53 с, собирается на [Remotion](https://www.remotion.dev). Сценарий — в [SCRIPT.md](SCRIPT.md).

```bash
cd demo
bun install
bun run frames   # кадры в public/frames через CLI Tusche из packages/cli
bun run studio   # предпросмотр в браузере
bun run render   # out/tusche-demo.mp4
```

`demo` — отдельный пакет вне workspaces репозитория, со своим `bun.lock`. Кадры и видео в git не попадают.

## Откуда материал

Все дизайны — настоящие результаты агента со скиллом 0.1.1 из прогона эвалов (ADR-010). Файлы `.pen` лежат в `sources/`. Шаги в левой панели взяты из транскрипта задачи `screen-mobile-tabs`. Промежуточные состояния экрана `frames.ts` получает из финального файла: убирает секции, которые агент к этому моменту ещё не построил, в том порядке, в каком он их строил.

## Публикация

Видео встраивается в README отдельной строкой со ссылкой `https://github.com/user-attachments/assets/…`. Ссылку даёт GitHub при перетаскивании файла в поле текста на сайте. Публичным вложение становится только после сохранения этого текста: из неотправленного черновика issue оно открывается одному автору. Для 0.1.0 видео загружено в описание [релиза](https://github.com/tusche-dev/tusche/releases/tag/v0.1.0). Проверка — `curl -sI <ссылка>` без входа должен вернуть 302, а не 404. Лимит — 10 МБ.
