# Как помочь проекту Tusche

[English](CONTRIBUTING.md) · **Русский**

Спасибо за интерес! Tusche на **этапе 0 — спецификация**. Сейчас больше всего пользы принесут:

1. **Тестовые файлы `.pen`**, которыми вы вправе делиться. Они станут эталонами для тестов круговой конвертации и рендера.
2. **Исправления в OpenPencil**, от которых мы зависим. Список — в разделе «Найденные риски» в [docs/dev/02-research.md](docs/dev/02-research.md).
3. **Ревью спецификаций** и issues с замечаниями.

## Языки

- **Пользовательская документация** (README, `docs/guide/`) — на **английском и русском**. У каждой страницы в `docs/guide/en` есть пара с тем же именем в `docs/guide/ru`.
- **Документация для разработки** (`docs/dev/`: видение, архитектура, спецификации, ADR) — на **русском**.
- **Скилл агента** (`docs/dev/drafts/SKILL.md`, позже `packages/skill`) — на **английском**: так модели надёжнее выполняют инструкции.

## Основные правила

- **«Чистая комната».** Поддержку `.pen` пишем только по публичной документации (<https://docs.pencil.dev/for-developers/the-pen-format>) и наблюдениям за самими файлами. Код, бинарники, тексты скиллов, картинки и другие ассеты pen.dev не копируем, pen.dev не декомпилируем.
- **Решения оформляем как ADR** в `docs/dev/adr/`.
- **Conventional commits:** `feat:`, `fix:`, `docs:`, `chore:` и т. д.

## Разработка (с фазы 1)

```bash
bun install
bun run check   # типы, линтер, тесты
```
