# Fixtures

Эталонные файлы для тестов круговой конвертации, миграций и рендера (фаза 1).

| Файл | Версия `.pen` | Что покрывает |
|---|---|---|
| `pen/eval/design.pen` | 2.17 | Компоненты и инстансы (~360 `ref`), переменные с темами `mode: dark/light`, шейдерные заливки (`noise.glsl`, `noise-light.glsl`), градиенты, кириллица |

`pen/eval/baseline/*.png` — эталонные рендеры нод верхнего уровня eval (`@tusche/engine`, scale 1). Тест `packages/engine/test/baseline.test.ts` сравнивает с ними с порогом 0,1 % пикселей. Обновить: `bun packages/engine/scripts/render-baseline.ts fixtures/pen/eval/design.pen --update`. Перед этим сверить с экспортом pen.dev (см. [02-research](../docs/dev/02-research.md)).

Правила:
- Файлы **не редактируем руками**: это «снимки» реальных документов pen.dev. Если нужен изменённый вариант, кладём его отдельным файлом.
- Ассеты лежат рядом с файлом по тем же относительным путям, что и в оригинале.
- Клиентские и приватные макеты в репозиторий не попадают. Их используем только локально: рендеры скрипта по умолчанию пишутся в `.tusche/renders/` (в `.gitignore`).
