# Tusche

[English](README.md) · **Русский**

> *Tusche* (нем.) — тушь. Название рабочее, см. [ADR-000](docs/adr/ru/000-name.md).

**Tusche — открытый дизайн-холст, рассчитанный в первую очередь на ИИ-агента.** Ваш агент для кода (Claude Code, Codex, любой MCP-клиент) рисует, правит и проверяет макеты интерфейсов на бесконечном холсте. Работает он на *вашей собственной* подписке: без дневных лимитов и без отдельного аккаунта.

Проект объединяет:

- **движок [OpenPencil](https://github.com/open-pencil/open-pencil)** (MIT): рендер на Skia/CanvasKit, flex- и grid-раскладку на Yoga, scene graph уровня Figma, импорт `.fig`, экспорт в PNG/SVG/PDF;
- **агентный подход, который сделал популярным pen.dev**: минимальный набор MCP-инструментов вокруг одного транзакционного `execute`, дизайн-скилл, который прививает агенту вкус, стилевые архетипы и самопроверку по скриншотам;
- **открытый формат `.pen`** в качестве основного: обычный JSON рядом с кодом, читаемые диффы в git, совместимость с уже имеющимися файлами.

## Статус

**Фаза 0 — исследование и спецификация.** Кода продукта пока нет. В репозитории лежат видение, исследование, спецификации и архитектурные решения, по которым будет собираться MVP.

| Фаза | Что входит | Статус |
|---|---|---|
| 0 | Исследование, спецификации, ADR | ✅ в этом репозитории |
| 1 | MCP-«компаньон»: чтение и запись `.pen`, движок `execute`, скриншоты без UI, скилл, CLI | запланировано |
| 2 | Десктоп-приложение (Tauri + Vue SDK OpenPencil), панель агента, prompt-ноды, стилевые архетипы | запланировано |
| 3 | Параллельные агенты, библиотеки компонентов, синхронизация токенов между дизайном и кодом | запланировано |

## Зачем

pen.dev сделал работу агента платной. На бесплатном плане агент может работать в приложении только 5 дней в месяц. Это касается даже вашего собственного Claude Code, подключённого по MCP. Tusche оставляет этот цикл бесплатным и локальным, а файлы с макетами — в открытом формате, который вы контролируете.
