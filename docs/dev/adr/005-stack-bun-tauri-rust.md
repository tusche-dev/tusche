# ADR-005 · Стек: ядро на TypeScript и Bun, Rust только в оболочке Tauri

- **Статус:** Принято
- **Дата:** 2026-10-20

## Контекст

Вопрос «а не писать ли это на Rust?» прозвучал явно. Факты:

- Самая тяжёлая работа уже делается скомпилированным нативным кодом, который поставляется как WASM: Skia (C++, через CanvasKit) рендерит, Yoga (C++) считает layout. Переписать их на Rust (vello, taffy) — значит строить свой движок, а от этого отказался ADR-001.
- Наш собственный код — это работа с форматом, мост, слой API, MCP-сервер, хост песочницы и UI. То есть ввод-вывод и связующий код, а не тяжёлые вычисления.
- Пакеты `@open-pencil/*` написаны на TypeScript, их десктопная оболочка — Tauri (Rust).
- Агенты пишут сниппеты `execute` на JavaScript, так что API они в любом случае видят как JS.
- ZSeven-W/openpencil показывает, что инструмент дизайна с ядром на Rust жизнеспособен, но это отдельный движок со своим форматом (см. [02-research](../02-research.md)).

## Решение

- **Пакеты ядра:** TypeScript (strict, ESM) в workspace на **Bun**. Bun быстр для тестов и скриптов, а опубликованные пакеты работают и на Node ≥ 22. Инструменты те же, что у OpenPencil.
- **Схемы:** Valibot (его же используют OpenPencil и его MCP).
- **MCP:** официальный TypeScript SDK для MCP.
- **Песочница:** QuickJS в WASM (ADR-003).
- **Десктоп (фаза 2):** **Tauri v2**. Его Rust-часть берёт на себя то, в чём Rust силён:
  - нативные окна и меню;
  - ассоциации файлов и слежение за ними;
  - связку ключей ОС;
  - автообновление;
  - запуск CLI агентов и надзор за ними (ADR-004).

  Electron отвергнут: это приложение размером около 200 МБ, ровно то, что сейчас поставляет pen.dev.
- **Когда Rust станет кандидатом на большее:** если профилирование в фазе 1 найдёт важное горячее место — например, каноническую сериализацию очень больших документов или разворачивание инстансов, — его можно вынести в модуль Rust → WASM без смены архитектуры.

## Последствия

- ➕ Один язык для ядра, MCP, preview и фронтенда десктопа; самый быстрый путь к MVP; помогать проекту легко.
- ➕ Rust используется там, где он даёт пользу, и есть понятный путь расширить его применение.
- ➖ Для фазы Tauri нужны навыки Rust для оболочки.
- ➖ У JavaScript есть пределы производительности на очень больших документах; их смягчают ленивое разворачивание инстансов и инкрементальная проекция.
