# ADR-003 · `execute` выполняет JavaScript агента в песочнице QuickJS (WASM)

- **Статус:** Принято
- **Дата:** 2026-10-20

## Контекст

Главный инструмент агента выполняет JavaScript-сниппеты, написанные LLM. Требования:

- **Изоляция:** никакого доступа к файловой системе, сети и процессам — только через наш API.
- **Лимиты:** время CPU, память, число операций.
- **Транзакции:** при ошибке откатывается всё.
- **Глобальные переменные сохраняются** между вызовами, отдельно для каждого документа.
- Одинаково работает под Bun, Node, Tauri и в браузере (preview).

Варианты:

1. Контексты `node:vm` или аналоги `ShadowRealm` в Bun. Это не граница безопасности, и они привязаны к конкретной среде выполнения.
2. Только декларативные JSON-операции (как `batch_update` в OpenPencil). Безопасно, но пропадают циклы и хелперы — а именно они делают сниппеты короткими.
3. **Движок QuickJS, скомпилированный в WebAssembly** (`quickjs-emscripten` / `quickjs-wasi`). Настоящая граница интерпретатора, переносимость, ограничение по времени через прерывания и по памяти. pen.dev использует решение того же класса.

## Решение

Вариант 3 на базе `quickjs-emscripten` (MIT), если бенчмарк на этапе 1.4 не покажет, что другая WASM-сборка лучше.

- Хост-функции (`Insert`, `Get`, …) привязываются к виртуальной машине. Аргументы передаются внутрь копией через JSON, результаты так же копируются наружу. Хост-объекты внутрь не попадают.
- Обработчик прерываний следит за лимитом времени; у рантайма есть потолок памяти.
- Глобальные переменные сохраняются так: сериализуются **только JSON-совместимые собственные свойства**, которые сниппет присвоил глобальному объекту. Хранятся они в `DocumentSession`.
- Транзакции реализованы на стороне хоста (снапшот `PenDocument` с разделением структуры) и не зависят от VM.
- Сниппет почти не предобрабатывается: номера строк сохраняются для сообщений об ошибках, транспиляции нет. Агенты пишут на обычном ES2020.

## Последствия

- ➕ Недоверенный код агента можно выполнять безопасно; движок один и тот же везде.
- ➕ Короткие сниппеты с циклами и хелперами тратят меньше токенов, чем гранулярные инструменты.
- ➖ Копирование JSON между хостом и VM стоит времени на огромных результатах `Get`. Решение: visitor'ы выполняются **внутри** VM над лениво материализуемым деревом, наружу возвращаются только собранные значения.
- ➖ На тяжёлых вычислениях QuickJS медленнее V8; для сниппетов дизайна это приемлемо.
