# ADR-000 · Название проекта: Tusche (рабочее)

- **Статус:** Принято (рабочее название; до первого публичного релиза можно пересмотреть)
- **Дата:** 2026-10-20

## Контекст

Проекту нужно название, которое:

- не использует «pen.dev», «Pencil» и «OpenPencil» — чтобы не путаться с товарными знаками и с двумя уже существующими проектами OpenPencil;
- короткое, произносится и по-английски, и по-русски, годится как команда CLI;
- свободно на npm, как домен `.dev` и, по возможности, как организация на GitHub.

Доступность проверена 2026-10-20 (реестр npm, GitHub API, NS-записи DNS):

| Кандидат | npm | Пользователь/организация на GitHub | Домен `.dev` | Вывод |
|---|---|---|---|---|
| Nib | занят (`nib`) | занят | свободен | ✗ npm |
| Stylo | занят | занят | — | ✗ |
| Grafit | свободен | занят | заняты (grafit.dev, grafit.app) | ✗ домены |
| Inkline | занят (UI-фреймворк) | занят | — | ✗ конфликт |
| Vellum, Linework, Chalkline | заняты | заняты | заняты | ✗ |
| Stilus | свободен | занят | свободен | возможно |
| **Tusche** | **свободен** (`tusche`, `@tusche/*` не используются) | `tusche` занят; **`tusche-dev` свободен** | **tusche.dev свободен** | ✓ |

## Решение

Берём **Tusche**.

- *Tusche* по-немецки — чертёжная тушь, а русское слово «тушь» происходит именно от него. У русскоязычных пользователей название сразу вызывает понятную ассоциацию, а по-английски звучит ремесленно.
- CLI: `tusche`. npm-scope: `@tusche/*` (зарегистрировать). Организация на GitHub: `tusche-dev` (создать). Домен: `tusche.dev` (зарегистрировать).
- Произношение: «TOO-sheh» по-английски, «туше» по-русски — заодно перекликается с фехтовальным *touché*.

## Последствия

- До любого публичного анонса зарегистрировать npm-организацию, организацию на GitHub и домен: имена могут занять.
- Если название поменяется до релиза, заметно оно упоминается только в README, NOTICE, CLAUDE.md и этом ADR; пакетов с таким именем пока нет.
