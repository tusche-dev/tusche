# ADR-004 · Подключение агентов: MCP для внешних, в приложении — запуск CLI самого пользователя

- **Статус:** Принято для фазы 1; часть про фазу 2 перепроверить перед реализацией
- **Дата:** 2026-10-20

## Контекст

Весь смысл Tusche в том, что холстом управляет **подписка самого пользователя** на агента (Claude Code Pro / Max, ChatGPT / Codex, Gemini), а Tusche ничего не тарифицирует. Подключить агента можно двумя способами:

1. **Внешний агент → Tusche по MCP.** Пользователь запускает Claude Code в терминале и добавляет Tusche как MCP-сервер. Подписку расходует сам Claude Code — так же, как с любым другим MCP-сервером.
2. **Панель агента внутри десктопного Tusche** (фаза 2). Варианты:
   - а. встроить Claude Agent SDK и дать пользователю войти в аккаунт Claude прямо в Tusche;
   - б. встроить SDK с API-ключом, который даёт пользователь;
   - в. **запускать установленный у пользователя `claude` CLI** (или `codex`, `gemini`) дочерним процессом с заранее настроенным MCP-сервером Tusche и транслировать его вывод в панель.

В документации Agent SDK от Anthropic сказано: без предварительного одобрения сторонним разработчикам нельзя предлагать в своих продуктах вход через claude.ai и лимиты подписки — нужно использовать аутентификацию по API-ключу. Поэтому вариант 2а нам без одобрения недоступен.

## Решение

- **Фаза 1:** только MCP (вариант 1). Подключение — одной командой: `claude mcp add tusche -- npx -y @tusche/cli mcp`.
- **Фаза 2:** по умолчанию вариант 2в. Панель — это интерфейс над собственным CLI пользователя, который аутентифицирован так, как пользователь его настроил.
  - Пользователям без CLI предлагаем вариант 2б: API-ключ, который хранится в связке ключей ОС.
  - Вариант 2а **не** реализуем, пока Anthropic явно это не разрешит.
- Tusche никогда не проксирует трафик к моделям через какой-либо сервер.

## Последствия

- ➕ Соответствие правилам заложено в саму конструкцию: Tusche никогда не касается учётных данных подписки.
- ➕ Работает с любым CLI-агентом, который поддерживает MCP, а не только с Claude.
- ➖ Панель в приложении зависит от локально установленного CLI и от формата его вывода (`claude -p --output-format stream-json`). Решение: адаптер под каждый CLI; если он не справляется, остаётся обычный терминал.
- Перед стартом фазы 2 перепроверить актуальные условия Anthropic, OpenAI и Google и обновить этот ADR.
