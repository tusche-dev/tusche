# 08 · Roadmap

Оценки рассчитаны на одного разработчика, работающего с агентом. Они грубые и нужны, чтобы упорядочить работу, а не чтобы обещать даты.

## Фаза 0 — спецификация ✅

Видение, исследование, PRD, архитектура, спецификация `.pen`, API для агента, черновик скилла, ADR. Документация для разработки — на русском, пользовательская — на английском и русском. Практическая проверка пакетов OpenPencil (выполнена 2026-10-20).

## Фаза 1 — MCP-компаньон (≈ 4–6 недель)

Сделано: 1.1–1.4 (2026-10-20). Результаты проверки на реальных файлах — в [02-research](02-research.md). Миграция по факту 2.6 → 2.21 нужна только для image-заливок; `icon_font` в реальных файлах пока не встречался. Рендеры 4 реальных файлов совпадают с экспортом pen.dev на 0,1–1,4 % пикселей (без шейдеров), пятый сверен визуально.

Baseline эвалов скилла 0.1.0 (2026-10-20): `claude-opus-5-5`, 15 задач из 15 дали файл, ошибок сессий нет. Lint: 0 ошибок, 39 предупреждений, из них 37 `op/touch-target-size` (в основном ложные: строка ссылок считается одной целью) и 2 `clipped` (задуманная прокрутка); после поправок lint и скорера baseline пересчитан: 35 предупреждений, 33 `touch-target-size`, правок вне `scope` 0. 103 вызова `execute`, 5 неудачных, все исправлены с первой попытки. 4,39 млн токенов, 234 хода, $7,30. Главные проблемы — пробелы в скилле: `null` в `Insert`, `strokeWidth` по сторонам, формат `stroke`, пути из `resolveInstances`; спейсеры из `guide/web-app.md` дают `zero-size`; скриншот почти в каждом `execute` — основной расход токенов. Скилл 0.1.1 закрывает эти пробелы; поправки lint и скорера — в `@tusche/engine` и `evals/`.

Baseline скилла 0.1.1 (2026-10-23, [evals/baseline](../../evals/baseline/summary.md)) принят `compare.ts`: 15 из 15 файлов, lint 0 ошибок и 23 предупреждения (все `touch-target-size`, против 33), `execute` 80 вызовов, неудачных 1 (против 5), 3,61 млн токенов (−18 %), 215 ходов, $7,07. Первое сравнение было отклонено: ошибка контраста у компонента, лежащего прямо на холсте (полупрозрачная заливка без фона считалась поверх белого), и 6 `clipped` (декор за краем карточки, список под таб-баром). Обе находки — ложные, lint поправлен: без непрозрачного фона контраст не оценивается, задуманная обрезка (`below-fold`, `bleed`) не считается `clipped`. Оба прогона пересчитаны этими правилами.

Preview (2026-10-23, [ADR-011](adr/011-preview.md)): пакет `@tusche/preview` и `tusche preview`. Сервер следит за файлом, раскладывает его движком и шлёт на страницу только изменённые корни. Страница рисует готовый scene graph через WebGL (`@tusche/engine/preview`), поэтому картинка совпадает со скриншотами агента: восстановленная сцена даёт пиксель в пиксель тот же рендер, что `scene.export`. Проверено в браузере на `design.pen`: правка через `tusche exec` появляется без перезагрузки, клик даёт pen-путь внутри инстанса.

Цель: Claude Code рисует в `.pen` через Tusche и получает скриншоты, а файлы остаются совместимыми с pen.dev.

## Фаза 2 — десктоп (≈ 6–10 недель)

- Приложение на Tauri v2 с `@open-pencil/vue`: холст, слои, инспектор свойств `.pen`, редактирование текста, общий с агентом undo.
- Обратный маппинг: ручные правки → изменения в `.pen`.
- Панель агента, которая запускает у пользователя `claude` / `codex` / `gemini` CLI с заранее настроенным MCP Tusche; потоковый лог; кнопка остановки.
- Ноды prompt / note / context; визуальное оформление `placeholder`; курсор агента.
- Импорт из браузера (URL → слои) через HTML-импорт OpenPencil.
- Шейдерные заливки через CanvasKit RuntimeEffect (трансляция GLSL → SkSL для типичных случаев).
- Установщики для Windows, macOS и Linux; автообновление.

**Выход:** сценарии 3–5 из PRD проходят в приложении; человек без навыков разработки может руками подправить экран, сделанный агентом.

## Фаза 3 — продвинутые возможности

- Параллельные агенты и варианты (разделить работу по фреймам; режим «N направлений»).
- `imports`: библиотеки компонентов между файлами; встроенные открытые киты (свои или под пермиссивной лицензией, например в духе shadcn).
- Двусторонняя синхронизация дизайн-токенов с CSS / Tailwind v4.
- Выполнение нод `script` в песочнице.
- Опциональная совместная работа через слой Yjs / WebRTC от OpenPencil.
