# Справочник CLI

[English](../en/cli.md) · **Русский**

Установка глобально: `npm i -g @tusche/cli` (или `bun add -g @tusche/cli`). Можно и без установки: `npx @tusche/cli <команда>`.

| Команда | Что делает |
|---|---|
| `tusche mcp` | Запускает MCP-сервер на stdio. Именно эту команду запускает ваш агент. |
| `tusche preview <file.pen> [--port n] [--open]` | Поднимает живой просмотр на `http://127.0.0.1:4848/` (или на следующем свободном порту). Страница перерисовывается при каждом сохранении файла — агентом или кем-то ещё. Перетаскивание или прокрутка двигают холст, Ctrl/⌘ + прокрутка масштабирует, клик по слою показывает его id. `--open` открывает браузер. Работает до Ctrl+C. |
| `tusche render <file.pen> [--node <id>…] [--scale 2] [--max-side px] [--out dir/]` | Рендерит в PNG фреймы верхнего уровня или указанные ноды, по файлу `<id>.png` на ноду. Папка по умолчанию — `<имя>.renders`. |
| `tusche export <file.pen> --format png\|jpeg\|webp\|svg\|html-tailwind [--node <id>…] --out <path>` | Экспортирует ноды в файлы. С `--node` — один файл с этими нодами, без него — по файлу на каждый фрейм верхнего уровня в папке `--out`. PDF пока недоступен. |
| `tusche exec <file.pen> <script.js \| -> [--create] [--out dir/]` | Выполняет `execute`-сниппет над файлом без агента (`-` — читать из stdin). Файл сохраняется сразу, скриншоты пишутся в `--out`. Если сниппет упал, код выхода 1. |
| `tusche lint <file.pen> [--node <id>] [--info] [--format text\|json]` | Ищет проблемы вёрстки и дизайна: обрезанный контент, невидимый текст, неизвестные шрифты, низкий контраст, мелкий текст и другие. При ошибках код выхода 1. |
| `tusche validate <file.pen> [--info]` | Проверяет файл по схеме `.pen`. При ошибках код выхода 1. |
| `tusche migrate <file.pen> [--dry-run]` | Обновляет старый файл `.pen` до текущей версии формата, сохраняя его оформление. |

Код выхода 2 — неверная команда или опция. `tusche --help` выводит полный список.

## Запуск из исходников

Чтобы попробовать ещё не выпущенные изменения, склонируйте репозиторий, выполните `bun install` и везде, где на этой странице написано `tusche`, используйте `bun <repo>/packages/cli/src/index.ts <команда>`.

## Переменные окружения

| Переменная | Значение |
|---|---|
| `TUSCHE_ROOT` | Дополнительная папка, куда разрешено писать `Export`. По умолчанию запись идёт только рядом с файлом `.pen`. |
| `TUSCHE_ALLOW_REMOTE_ASSETS=1` | Разрешает картинки по ссылкам `http(s)` в заливках |
| `TUSCHE_FONTS_OFFLINE=1` | Не скачивать шрифты, брать только кэшированные и системные |
| `TUSCHE_CACHE_DIR` | Где хранятся скачанные шрифты и иконки (по умолчанию `~/.cache/tusche`) |
| `TUSCHE_CALL_LOG` | Только для `tusche mcp`: дописывать в этот файл JSON-строку на каждый вызов инструмента (инструмент, результат, время; нужно для эвалов скилла) |

## Пример: проверка дизайна в CI

```yaml
# .github/workflows/design.yml
- run: npx @tusche/cli lint design/app.pen
- run: npx @tusche/cli render design/app.pen --out design/shots
```
