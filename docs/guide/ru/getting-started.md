# Быстрый старт

[English](../en/getting-started.md) · **Русский**

> **Самый быстрый способ:** вставьте в агента промпт из раздела [«Пусть агент всё настроит»](../../../README.ru.md#пусть-агент-всё-настроит). Агент пройдёт [инструкцию для агентов](../../agent-setup.md) и подключит Tusche сам. Шаги ниже делают то же вручную.

## Что понадобится

- **ИИ-агент с поддержкой MCP:** Claude Code, Codex CLI, Gemini CLI, OpenCode или любой другой MCP-клиент. Tusche работает через *ваш* агент и *вашу* подписку. Своего аккаунта и лимитов у него нет.
- **Bun ≥ 1.3 или Node.js ≥ 22.**
- По желанию — готовые файлы `.pen` из pen.dev. Tusche открывает их как есть.

## 1. Подключите Tusche к агенту

**Claude Code:**

```bash
claude mcp add tusche -- npx -y @tusche/cli mcp
```

Проверьте командой `/mcp` внутри Claude Code: в списке должен появиться `tusche` со своими инструментами.

**Другие MCP-клиенты** — добавьте stdio-сервер:

```json
{
  "mcpServers": {
    "tusche": { "command": "npx", "args": ["-y", "@tusche/cli", "mcp"] }
  }
}
```

Если на Windows клиент не находит `npx`, укажите `"command": "cmd", "args": ["/c", "npx", "-y", "@tusche/cli", "mcp"]`.

**Чтобы попробовать ещё не выпущенные изменения,** склонируйте репозиторий, выполните в нём `bun install` и подключите сервер из клона:

```bash
claude mcp add tusche -- bun /path/to/tusche/packages/cli/src/index.ts mcp
```

Сервер работает в папке, где запущен агент, поэтому `design/app.pen` появится в вашем проекте.

## 2. Попросите сделать дизайн

Откройте агента в папке проекта и напишите:

> Сделай экран онбординга для мобильного трекера привычек в `design/app.pen`.

Агент:

1. прочитает скилл Tusche;
2. создаст или откроет `design/app.pen`;
3. задаст цвета и шрифты, соберёт экран по секциям и проверит каждую;
4. покажет скриншоты прямо в чате.

Файл сохраняется автоматически. Это обычный JSON, его можно коммитить рядом с кодом.

## 3. Смотрите в реальном времени (по желанию)

```bash
npx @tusche/cli preview design/app.pen
```

Откройте адрес, который напечатает команда (или добавьте `--open`). Страница перерисовывает макет при каждом сохранении файла, поэтому видна каждая правка агента. Клик по слою показывает его id — удобно, когда просите агента поменять именно этот элемент.

## 4. Продолжайте работу

- «Сделай карточки плотнее и добавь тёмную тему».
- «Покажи три варианта hero-блока рядом».
- «Сверстай экран настроек из `design/app.pen` в нашем приложении на Next.js».

## Файлы из pen.dev

Открываются так же: просто укажите агенту путь к файлу. Tusche сохраняет все свойства, которые не понимает, и записывает файл в том же формате, поэтому он по-прежнему открывается в pen.dev.
